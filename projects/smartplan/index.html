What It Is

SmartPlan is my biggest project right now. It's a to-do app with an AI assistant that lets you automatically plan tasks through natural language. It also features a focus mode, where you can set a timer and work for a time block, which you can adjust as you go if needed.

I've used this project to practice building for multiple platforms, including web, Android, and iOS.

Highlights

AI Assistance

The assistant helps with planning so tasks feel more actionable and less scattered.

Cross-Platform

I'm using it as a way to learn how to ship the same product across web and mobile surfaces.

Personal Focus

It's the project I'm putting the most energy into while I'm still in the middle of the Flavortown contest.
